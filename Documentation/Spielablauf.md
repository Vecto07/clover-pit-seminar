- Phasenbeginn:
    - Schulden werden festgelegt 550-650 (Phase.1)
    - Zeitraum wird festgelegt
    - Budget wird gegeben
- Individueller Tagesbeginn:
    - Gamblen
    - Spins kaufen
    - Spinnen für Gewinne
      -> Items werden auf den Spin angewendet
    - Bei jedem Spin Chance auf "Kill Switch" - Gewonnenes Geld wird auf 0 gesetzt
- Nach dem Spinnen:
    - Items können im Shop gekauft werden
      -> Max. Inventar: 5 Items
    - Schulden können beglichen werden, auch nur teilweise
- Tageswechsel:
    - Gespartes Budget wird verzinst 5%
    - Schulden werden höher verzinst! 10%

- Spezialisierter Build -> Höhere Wahrscheinlichkeit von guten Symbolen
