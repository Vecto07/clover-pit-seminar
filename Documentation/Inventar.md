Der Spieler hat ein Inventar, in dem eine maximale Anzahl an [[Items]] gehalten werden kann.
- Maximal 5(?) Items können gehalten werden
- Aus dem Inventar können Items für einen Teil ihres Kaufwerts wieder verkauft werden
- Die Reihenfolge im Inventar kann den Effekt der Items beeinflussen, nach der Reihenfolge 1-5
